# تطبيق Smart Gym Manager لأندرويد (APK) — خادم + إدارة + رابط Tailscale Funnel ثابت

## الفكرة
- التطبيق يحوي خادم Node.js (نفس server.js) يعمل داخل الهاتف، ومعه برنامج صغير (tsfunnel) يفتح Tailscale Funnel فيعطي **رابط https ثابتا** للمشتركين.
- الواجهة تفتح مباشرة داخل التطبيق (WebView) على http://localhost:3000 .
- خدمة أمامية + إعفاء من توفير البطارية + تشغيل تلقائي بعد إعادة تشغيل الهاتف.

## بناء الـ APK (مرة واحدة، من السحابة بدون تثبيت أي شيء)
1. أنشئ حسابا على github.com ثم مستودعا جديدا (يمكن أن يكون Private).
2. ارفع **محتوى هذا المجلد كله** (Add file ← Upload files) مع المجلد المخفي `.github`.
   إن لم يُرفع `.github`: Add file ← Create new file، واكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**. يستغرق نحو 10 دقائق.
4. عند النجاح افتح العملية ← **Artifacts** ← حمّل **SmartGymManager-apk** (يحوي app-debug.apk).
5. إن فشل البناء: افتح الخطوة الحمراء، وانسخ آخر 40 سطرا من الخطأ وأرسلها لتصحيحها.

## عند الزبون
1. ثبّت app-debug.apk (يسمح بـ «التثبيت من هذا المصدر»).
2. افتح التطبيق، وافق على إعفاء البطارية والكاميرا/الميكروفون عند الطلب.
3. أنشئ حساب المدير.
4. من صفحة الإدارة اضغط **🌍 تفعيل الرابط العام**: سجّل الدخول في Tailscale (حساب Google مجاني) مرة واحدة، وفعّل Funnel و HTTPS من الرابط الذي يظهر ثم أعد الضغط. يظهر رابط ثابت يُحفظ تلقائيا.

## ملاحظات
- التطبيق مبني بـ targetSdk 28 عمدا (للتثبيت اليدوي فقط، ليس لمتجر Google Play).
- لم يُجرَّب هذا المشروع على جهاز قبل التسليم؛ أرسل أي خطأ لتصحيحه.
- البيانات داخل ذاكرة التطبيق: حذف التطبيق يحذفها. أضف لاحقا خيار تصدير/نسخ احتياطي إن لزم.
